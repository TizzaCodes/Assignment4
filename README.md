# IGD Replication — Lohia et al. (2019)

**Repository:** https://github.com/TizzaCodes/Assignment4

This repository contains a Jupyter notebook implementing a partial reproduction of Individual Group Debiasing (IGD) from Lohia et al. (2019), *Bias Mitigation Post-processing for Individual and Group Fairness*.

## Contents

- `Assignment4_IGD.ipynb` — data preparation, baseline logistic-regression models, IGD post-processing, and evaluation.
- `requirements.txt` — Python dependencies.
- `igd_replication_results.csv` — previously reported result values; regenerate after running the notebook locally.
- `.gitignore` — excludes local environments and temporary files.

## Requirements

- Python **3.11** recommended.
- Internet connection on the first run, because AIF360 downloads the Adult, German Credit, and COMPAS datasets.
- Jupyter support in VS Code (Python and Jupyter extensions).

## Reproduce the results

From the repository root:

1. Clone this repository:
   ```bash
   git clone https://github.com/TizzaCodes/Assignment4.git
   cd Assignment4
   ```
2. Create and activate a virtual environment.

   **Windows PowerShell**
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS / Linux**
   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   python -m ipykernel install --user --name igd-replication --display-name "Python (IGD replication)"
   ```
4. Open `Assignment4_IGD.ipynb` in VS Code, select the **Python (IGD replication)** kernel, then choose **Restart Kernel and Run All Cells**.
5. Check that every cell completes, save the notebook, and confirm the final export cell regenerates `igd_replication_results.csv`.

## Method overview

The notebook fetches the Adult, German Credit, and COMPAS datasets; defines six protected-attribute experiments (Adult sex/race, German Credit sex/age, COMPAS sex/race); calculates DP_Diff, DIR, and consistency on original labels; makes stratified 60/20/20 splits; trains logistic-regression baseline models; estimates individual bias and selects an IGD threshold using validation data; and evaluates held-out test predictions using DP_Diff, DIR, consistency, and balanced accuracy.

## Metric interpretation

- **DP_Diff:** favourable prediction rate for the unprivileged group minus that for the privileged group. Closer to 0 indicates smaller group disparity.
- **DIR:** unprivileged favourable prediction rate divided by privileged favourable prediction rate. Closer to 1 indicates greater parity.
- **Consistency:** nearest-neighbour measure of whether similar records receive similar predictions. Higher is better.
- **Balanced accuracy:** average of sensitivity and specificity.

## Reproduction scope and limitations

This is a **partial reproduction**, not an exact reproduction of every experiment in the paper:

- The notebook uses logistic regression; the original study also evaluates random forests.
- It uses one fixed random seed (69) and one stratified 60/20/20 split per experiment, rather than the paper's repeated-partition evaluation.
- The paper describes selecting the IGD threshold under a disparate-impact constraint but does not specify the exact search implementation used here. The notebook tests observed validation bias-score thresholds (plus thresholds that correct none or all) and selects the candidate closest to the target DIR interval [0.8, 1.25].
- The consistency calculation uses five nearest neighbours after one-hot encoding; preprocessing and distance choices can affect results.

The CSV currently contains previously reported values and has **not been freshly regenerated by a clean run in this environment**. Please run the notebook locally and replace the CSV with the fresh output before treating the numbers as final. Compare the direction and interpretation of findings rather than claiming exact numerical replication.
